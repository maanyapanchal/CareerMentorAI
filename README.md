# CareerMentor AI

CareerMentor AI is an AI-powered career preparation platform built using Python and Streamlit.

## Features

* Company-specific interview preparation
* AI-generated interview questions
* AI-generated sample answers
* Role-based preparation
* Difficulty-based preparation

## Technologies Used

* Python
* Streamlit
* Groq API
* Llama 3.3

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python -m streamlit run app.py
```
