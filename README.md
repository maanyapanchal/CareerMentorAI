# CareerMentor AI

## Overview

CareerMentor AI is an AI-powered interview preparation and self-assessment platform built using Python and Streamlit.

The application helps students prepare for technical interviews by generating company-specific interview questions, sample answers, and AI-powered feedback on user-submitted responses.

---

## Features

### Interview Question Generation

* Generate interview questions based on:

  * Job Role
  * Company
  * Topic
  * Difficulty Level

### AI-Generated Sample Answers

* Provides beginner-friendly sample answers.
* Helps users understand expected interview responses.

### Quick Self-Assessment

* Users can answer interview questions in their own words.
* AI evaluates the answer and provides:

  * Accuracy Score
  * Completeness Score
  * Communication Clarity Score
  * Strengths
  * Weaknesses
  * Suggested Improvements
  * Improved Model Answer

### Company-Specific Preparation

Supports preparation for companies such as:

* Infosys
* TCS
* Wipro
* Accenture
* Amazon
* Google
* Microsoft

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```
